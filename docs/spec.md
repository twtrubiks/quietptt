# 規格

App 每個功能該怎麼運作。改功能之前先讀對應的段落，改了行為要一起更新這裡。
不做、先不做、之後可能做的在 `CLAUDE.md` 與 `docs/ideas.md`。

## 連線

- 兩種：**SSH**（預設，`bbs@ptt.cc:22`）與 **WebSocket**（`wss://ws.ptt.cc/bbs`）。設定頁切換、存在 SharedPreferences `settings`，下次連線生效
- 兩種都吐 Big5-UAO，走同一套終端模擬與畫面辨識
- SSH 的 host key 寫死在 App 裡，對不上就拒絕連線並顯示「伺服器的 host key 對不上，請更新 App」
- 不送 keep-alive、不自己重連。連線被對方關掉或網路斷了就回登入頁，顯示「連線中斷」
- 連線逾時 15 秒

## 登入

- 登入頁：帳號、密碼、「記住帳號與密碼」（預設勾）、登入、設定
- 帳號、密碼預填記住的；只記帳號時密碼欄空著
- 流程（`Session.login`）：等「請輸入代號」→ 送帳號 → 等「請輸入您的密碼」→ 送密碼 → 中間的問題自動答：
  「重複登入」答 n（不踢別的連線）、「刪除錯誤嘗試紀錄」答 y、「請按任意鍵繼續」按 Enter、歡迎畫面與公告按 Enter →
  到「【主功能表】」算成功。整體最多等 45 秒
- 失敗：「密碼不對或無此帳號」顯示在登入頁；其他原因（過載、等太久）顯示原因，並可切到終端畫面看
- 成功就照「記住」存帳密（不記密碼時只存帳號），進我的最愛

## 記住帳號與密碼

- 預設開。密碼用 AndroidKeyStore 的 AES-256-GCM 加密後存 SharedPreferences `account`；帳號明碼
- 設定裡關掉：馬上把密碼丟掉，帳號留著。「忘記帳號與密碼」兩個都丟掉並登出
- 這份資料不備份、不隨換機傳輸（`allowBackup=false`、`data_extraction_rules.xml`）
- 解不開（金鑰被系統清掉）就當作沒記密碼，不報錯

## 前景與背景

- 整個 App 退到背景（`ProcessLifecycleOwner` 的 onStop）超過 **30 秒**就斷線
- 回到前景：若是因為退到背景才斷的、而且記得密碼，自動重新登入並回到我的最愛（之後：回到剛剛的看板或文章）；
  其他原因斷的回登入頁
- 轉螢幕不斷線、不重登（`Session` 在 `AppContainer`，不在 Activity）

## 我的最愛（首頁）

- 進來就從主選單按 `f` Enter，等「【我 的 最愛】」
- 每一筆：板名、看板標題、分類；未讀標記之後做；目錄（資料夾）先顯示但不能進
- 點一筆進看板；右上角「終端」切到終端畫面、「設定」進設定

## 看板

- 用 `s` 搜尋板名進板，等「看板《板名》」；板規／公告的「請按任意鍵繼續」自動按掉
- 列出目前這一頁的文章：推文數、標題、作者、日期。置底文（序號 ★）也列
- 點一筆進文章（之後：先把游標移到那篇再按 Enter）
- 之後：往上捲載入更舊的一頁（PAGE_UP 再解析）、推文數上色、搜尋

## 文章

- 現在：顯示終端目前這一頁的 23 列（等寬字）
- 之後（`Session.readArticle`）：PAGE_DOWN 一頁一頁翻到底，照每頁「目前顯示: 第 x~y 行」拼成完整內文，去掉重疊的那一行；
  推文（推／噓／→）分段上色；網址可點，交給外部瀏覽器；圖片**不**自動載入
- 返回鍵回看板（送左鍵）

## 終端畫面

- 原始的 24x80 文字（等寬、橫向可捲）加一排軟鍵：← → ↑ ↓ PgUp PgDn Enter Esc Space
- 任何一頁在認不出畫面時都給「切到終端畫面」；登入失敗也可以切過來看
- 之後：顏色（`Cell.attr`）、觸控手勢、文字輸入框

## 設定

- 連線方式（SSH／WebSocket）、深色模式（跟系統／淺色／深色）、記住帳號與密碼、登出、忘記帳號與密碼
- 沒有、以後也不會有的：遙測開關、背景通知、前景服務、電池最佳化

## 畫面辨識的特徵（`ScreenParser`）

| 頁面 | 認的字 |
| --- | --- |
| 登入 | 任一列有「請輸入代號」；上一次的錯誤看「密碼不對」「無此帳號」 |
| 密碼 | 「請輸入您的密碼」 |
| 重複登入 | 「您想刪除其他重複登入的連線嗎」 |
| 刪除錯誤嘗試 | 「您要刪除以上錯誤嘗試的記錄嗎」 |
| 任意鍵 | 「請按任意鍵繼續」 |
| 主選單 | 第 0 列有「【主功能表】」 |
| 我的最愛 | 第 0 列有「【我 的 最愛】」；列表從第 3 列到第 22 列，每列以「◎」（看板）或「□」（目錄）分左右 |
| 文章列表 | 第 0 列有「看板《…》」；每列：序號（或 ★）、1 格標記、推文數、日期、作者、標題 |
| 文章 | 第 23 列有「瀏覽」與「目前顯示」；進度看「第 x/y 頁」「第 a~b 行」 |
| 推文 | 「您覺得這篇文章」 |

這些是從記憶寫的，**以真的 fixture 為準**：抓到真的畫面後，哪個特徵不對就改這張表、改程式、改測試。
